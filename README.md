# so-262
Atividades e Exercícios de SO

Repositório para armazenar Atividades e Exercícios da Disciplina de Sistemas Operacionais:

- Atividades: contém as Atividades que o professor passa no classroom
- Exercícios: contém os Exercícios que o professor passa no classroom

Cada Atividade e Exercício vai ter sua própria subpasta juntamente com o seu README.md com a descrição do que foi proposto pelo professor.
